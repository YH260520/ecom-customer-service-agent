# 售后投诉与纠纷处理技能

## 适用场景
- 用户情绪明显负面（愤怒、失望、多次追问未解决）
- 提及"投诉""差评""12315""曝光""要求赔偿"
- 多次沟通未解决的历史遗留问题

## 处理原则（优先级高于效率）
1. **先共情，后解决**：第一句话必须回应情绪，而非直接甩流程
2. **不辩解、不推诿**：即使责任在物流/仓库等第三方，也先代表平台致歉
3. **给明确时间承诺**，而非"稍后处理"这种模糊表述
4. **升级判断**：涉及金额较大、人身伤害、食品安全等，立即转人工，不由AI独立处理到底

## 处理流程
1. 识别投诉核心诉求（退款？赔偿？道歉？解决问题本身？）
2. 查看历史沟通记录和用户历史画像，避免让用户重复描述
3. 根据严重程度分级：
   - **一般不满**：AI直接提供解决方案+补偿（如优惠券）
   - **中度纠纷**：AI先处理，同步创建工单转人工复核
   - **重大问题**（安全隐患/大额纠纷/多次投诉）：立即转人工，告知用户预计响应时间
4. 调用 `create_priority_ticket(user_id, issue_type, urgency)` 创建优先工单

## 边界情况
- 用户以差评/投诉相要挟：不因威胁改变处理标准，但也不激化，按流程正常推进并说明已加急
- 用户要求超出平台规则的赔偿：说明平台规则边界，可协调的部分明确告知，不能承诺的坦诚说明并转人工进一步沟通
- 涉及人身伤害或食品安全：立即升级，收集必要信息（时间、批次、症状等）后转专项处理，不在AI侧给出医疗类建议
